===============================================
Planner Project - API Docs (Frontend uchun)
===============================================

1. UMUMIY TUSHUNCHA
-------------------
Bu API project, task, user, role, permission, task status va task priority larni
boshqarish uchun ishlatiladi.

Authentication Laravel Sanctum token orqali ishlaydi.

Base URL:
  http://127.0.0.1:8000/api

Protected endpointlarda header yuboriladi:

  Authorization: Bearer {token}
  Accept: application/json
  Content-Type: application/json

Standart success response shakli:

{
    "status": true,
    "message": "...",
    "data": ...
}

Pagination response shakli:

{
    "status": true,
    "message": "...",
    "data": {
        "items": [],
        "pagination": {
            "total": 0,
            "current_page": 1,
            "last_page": 1,
            "per_page": 10,
            "prev_page_url": null,
            "next_page_url": null,
            "from": null,
            "to": null
        }
    }
}

Standart error response shakli:

{
    "status": false,
    "message": "...",
    "errors": null
}

9.2. Task yaratish — POST /api/projects/{project}/tasks
-------------------------------------------------------
Auth: Bearer token kerak
Permission: task.create

Validation:
  - assigned_to: nullable|exists:users,id
  - status_id: required|exists:task_statuses,id
  - priority_id: required|exists:task_priorities,id
  - title: required|string|max:255
  - body: nullable|string
  - deadline: nullable|date|after_or_equal:now

Request body:
{
    "title": "Create login API",
    "body": "Login endpoint yaratish",
    "assigned_to": 2,
    "status_id": 1,
    "priority_id": 1,
    "deadline": "2026-05-20"
}

Muhim:
  - assigned_to qilingan user shu projectga oldin biriktirilgan bo'lishi kerak.
  - status_id mavjud status bo'lishi kerak.
  - priority_id mavjud priority bo'lishi kerak.
  - deadline bugungi yoki kelajak sana bo'lishi kerak.
  - Aks holda backend validation/error response qaytaradi.

Response misol:
{
    "status": true,
    "message": "Task created successfully",
    "data": {
        "id": 1,
        "title": "Create login API",
        "body": "Login endpoint yaratish",
        "assigned_to": 2,
        "status_id": 1,
        "priority_id": 1,
        "deadline": "2026-05-20"
    }
}

16. FRONTEND UCHUN TAVSIYALAR
==============================

- Login qilingandan keyin token localStorage yoki cookie ichida saqlanadi.
- Har bir protected requestda Authorization: Bearer {token} yuboriladi.
- 401 bo'lsa user login sahifaga qaytariladi.
- 403 bo'lsa "Sizda ruxsat yo'q" degan xabar ko'rsatiladi.
- List sahifalarda filterlar query params orqali yuboriladi.
- Pagination qilingan endpointlarda data.items array bo'ladi.
- Pagination ma'lumotlari data.pagination ichida bo'ladi.
- Task listda filterlar birga ishlaganda AND bo'ladi.

Masalan:
  /api/projects/1/tasks?assigned_to=2&status_id=1

Bu assigned_to=2 VA status_id=1 bo'lgan tasklarni chiqaradi.

- Task create/update formda:
  1) avval project tanlanadi
  2) shu projectga biriktirilgan developerlar ko'rsatiladi
  3) status va priority tanlanadi
  4) deadline kiritiladi

- Role create/update formda permissionlar multi-select bo'lishi kerak.
- Project detail sahifada developers ro'yxati ko'rsatiladi.
- User detail sahifada role ko'rsatiladi.
